Minicurso Introdutório de Desenvolvimento Web Frontend

Este curso está sendo feito como projeto de extensão para nossa faculdade, será aplicado presencialmente em uma instituição ainda a ser definida. O material juntamente com vídeo-aulas estará todo disponível neste site.

Por este minicurso os professores visam iniciar no aluno o conhecimento e a aprendizagem do uso das ferramentas básicas do desenvolvimento web frontend e de outros recursos relacionados, de modo que comece a ganhar a capacidade de compreender e de construir a parte frontend de um website.

Mas o que é a parte frontend de um website? Acreditamos que podemos definir como: a parte dos códigos que rodam no computador do usuário de um website (o que chama-se lado do cliente).

As linguagens tratadas são HTML, CSS e JavaScript. Com códigos escritos nessas linguagens o navegador (seu Google Chrome, por exemplo) pode produzir a página a apresentar na tela do usuário.
